# 🛋️ Interior & Furniture E-Commerce Website

### Краткое описание
Учебный проект, представляющий собой современный и адаптивный **интернет-магазин дизайнерской мебели и предметов интерьера** («Всё, чего заслуживает ваш дом»). Сайт включает в себя главную страницу с акционными предложениями, структурированный каталог товаров с ценами и интерактивную корзину для оформления заказов.

Проект разработан с использованием **современных препроцессоров**, что позволило оптимизировать процесс верстки, сделать архитектуру стилей модульной и легко масштабируемой.

**Ключевой функционал сайта:**
* 📂 **Интуитивный каталог** — разделение мебели по категориям (для отдыха, работы, кухни, детской, ванной).
* 🏷️ **Специальные предложения** — блок с акционными товарами и демонстрацией старых/новых цен (диваны, люстры, комоды).
* 🛒 **Интерактивность** — полноценный интерфейс выбора товаров, добавления их в корзину и навигации по сайту.
* 📱 **Адаптивный дизайн** — сайт корректно отображается как на экранах стационарных компьютеров, так и на мобильных устройствах.

---

### Используемые технологии
* **HTML5** — создание семантической структуры интернет-магазина, разметка карточек товаров и форм.
* **Препроцессоры SCSS** — автоматизация стилей, использование переменных, вложенностей (nesting) и миксинов для создания чистой и расширяемой архитектуры стилей.
* **CSS3** — построение адаптивных сеток (Flexbox/Grid), оформление шрифтов и фоновых изображений.
* **JavaScript (ES6+)** — логика переключения страниц, управление корзиной товаров, расчет стоимости и обеспечение интерактивности интерфейса.
